# Morgan Redrup — Portfolio

Personal portfolio site, built with plain HTML/CSS/JS and hosted on GitHub Pages.

Live at: https://morgswy.github.io/

## Structure

- `index.html` — page content
- `styles.css` — styling, light/dark theme
- `script.js` — theme toggle, mobile nav
- `assets/` — images

## Local preview

Open `index.html` directly in a browser, or serve it locally:

```
python -m http.server 8000
```
